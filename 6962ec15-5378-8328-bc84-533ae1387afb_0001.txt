💡 1. Core API You’ll Use: Meta Graph API

The Graph API is Meta’s primary HTTP-based API for reading/writing almost all Facebook data your app has permission for — including Pages, Messages, Marketplace content, Commerce data, and more.

Key points:

    All interactions go through https://graph.facebook.com/v{version}/{node}.

You must create a Facebook Developer App, configure products (Messenger, Content Library, Pages, etc.), and request permissions.

Every request uses an access token (User, Page, or App token depending on context).
🛍️ 2. Facebook Marketplace Data
📌 Official API: Content Library and Marketplace API

Meta provides the Content Library API to surface Marketplace and Commerce data that your business manages — not arbitrary public Marketplace listings.

Typical data you can access (if authorized):

    Marketplace listings your business created

    Inventory and pricing

    Commerce manager objects (such as orders & products)

    Analytics/insights tied to listings

What you cannot fetch directly:

    Public Marketplace listings from other sellers

    Buyer contact or interaction data unless routed through your assets

📍 In other words: Facebook does not expose a public Marketplace search API for general scraping or open data pulls. If you’re seeing GitHub projects like kyleronayne/marketplace-api, they often wrap private or undocumented GraphQL endpoints, which isn’t official and can break unexpectedly.

    Create a Meta Developer App and link it to your Facebook Business/Commerce Manager.

    Add the Content Library product in the App dashboard.

    Request necessary permissions in your app (via App Review) such as commerce_management.

    Obtain a valid access token (Page or System User) with the correct scopes.

    Call the Marketplace/Content Library nodes via Graph API to fetch listings, products, or orders.

📌 Example A — Node.js Messenger Bot (Webhook + Send Reply)

// server.js
import express from 'express';
import bodyParser from 'body-parser';
import axios from 'axios';

const app = express();
app.use(bodyParser.json());

const VERIFY_TOKEN = process.env.MESSENGER_VERIFY_TOKEN;
const PAGE_ACCESS_TOKEN = process.env.PAGE_ACCESS_TOKEN;

// Webhook Verification
app.get('/webhook', (req, res) => {
  const mode = req.query['hub.mode'];
  const token = req.query['hub.verify_token'];
  const challenge = req.query['hub.challenge'];

  if (mode === 'subscribe' && token === VERIFY_TOKEN) {
    console.log('WEBHOOK_VERIFIED');
    res.status(200).send(challenge);
  } else {
    res.sendStatus(403);
  }
});

// Message Event Handler
app.post('/webhook', (req, res) => {
  const body = req.body;
  if (body.object === 'page') {
    body.entry.forEach(function(entry) {
      const webhookEvent = entry.messaging[0];
      const senderPsid = webhookEvent.sender.id;

      if (webhookEvent.message && webhookEvent.message.text) {
        callSendAPI(senderPsid, { text: `You said: ${webhookEvent.message.text}` });
      }
    });
    res.status(200).send('EVENT_RECEIVED');
  } else {
    res.sendStatus(404);
  }
});

// Send Message via Send API
function callSendAPI(senderPsid, response) {
  axios.post(`https://graph.facebook.com/v20.0/me/messages?access_token=${PAGE_ACCESS_TOKEN}`, {
    recipient: { id: senderPsid },
    message: response,
  }).catch(console.error);
}

app.listen(process.env.PORT || 1337, () => console.log('Messenger bot running'));

This is derived from the Node.js samples in the official repo (quick-start).
