📦 Setup Instructions

1
Install Docker
Docker is required to run FB Profile Processor. Choose your platform:
🍎 macOS 🪟 Windows 🐧 Linux
Requirements: Python 3.8+ and pip must be installed
After installing Docker, refresh this page to continue.
2
Clone Repository
Open your terminal and run:
git clone https://github.com/swipswaps/fb-profile-processor.git cd fb-profile-processor
3
Start Application
From inside the fb-profile-processor directory, run:
./install.sh
Alternative: You can also run docker-compose up -d directly
⏱️ First Time Setup: The first run will download Docker images (~500MB). This may take 5-10 minutes depending on your internet connection.
pip install -r requirements.txt && streamlit run dashboard.py
💡 Tip: Use a virtual environment: python -m venv venv && source venv/bin/activate
4
Access Dashboard
Your FB Profile Processor is now running! Open it in your browser:
http://localhost:8501
